# Thành phần bên thứ ba

Ứng dụng dùng các thành phần mã nguồn mở sau, mỗi thành phần theo giấy phép riêng.

- **Qt 6 và Qt for Python (PySide6, Shiboken6)**, © The Qt Company Ltd. và các tác giả, giấy phép GNU LGPL phiên bản 3. Ứng dụng liên kết động với Qt; bạn có thể thay các thư viện Qt trong thư mục cài đặt bằng bản tương thích khác. Mã nguồn: <https://download.qt.io/official_releases/QtForPython/> và <https://download.qt.io/official_releases/qt/>
- **Python**, © Python Software Foundation, giấy phép PSF. <https://www.python.org/>
- **PyInstaller bootloader**, giấy phép GNU GPL phiên bản 2 kèm ngoại lệ cho phép phân phối ứng dụng đóng gói. <https://pyinstaller.org/>
- Bộ cài Windows tạo bằng **Inno Setup**, © Jordan Russell, Martijn Laan. <https://jrsoftware.org/>

Toàn văn giấy phép GNU LGPL 3, GNU GPL 3 và Python nằm trong thư mục `giay_phep` của bản cài đặt.
